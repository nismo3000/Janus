# Prior-art search: novelty-driven grow/decay while serving (2026-10-03)

First pass, done with web search on 2026-10-03 for the provisional-patent exhibit. Not legal
advice; a professional search should follow. Purpose: know what exists, and state precisely what
Janus claims that none of it does.

## What Janus intends to claim (working statement)

A self-supervised world model that **serves a prediction-error ("surprise") signal on a live
stream while a co-resident learner trains it**, where (1) that served surprise, sustained after
the learner has had time to adapt, **triggers growth** of model capacity; (2) **disuse**, scored
over reservoir replay as well as recent traffic, **triggers decay** of capacity, with decayed
units **archived and pageable**, not destroyed; (3) all capacity lives in a **fixed slab
allocated at maximum size and gated by masks**, so the serving engine never recompiles and a
weight update stays a pointer flip; (4) routing keeps **parameters active per frame inside a
memory-bandwidth budget** while total parameters grow toward memory capacity.

## Closest references found

| Reference | What it does | How Janus differs |
|---|---|---|
| Growing When Required, Marsland et al. 2002 | Self-organising network adds a node when input novelty (activity below threshold) is high and the winning node is already well trained. | Oldest form of novelty-gated growth. Offline/unsupervised clustering, no serving loop, no decay-with-archive, no slab. Expect claim 1 "surprise triggers growth" alone to be anticipated by this; the claim must rest on the combination. |
| Neurogenesis-inspired dictionary learning, Garg et al. 2017 (arXiv 1701.06106) | Online dictionary learning: adds elements in proportion to representation error, removes useless elements via group sparsity. | Grow-on-error + prune-on-disuse, online. Linear dictionary, no served signal, elements destroyed not archived, no fixed-slab/no-recompile serving constraint, no bandwidth routing. The strongest single prior-art reference for the grow/decay pair. |
| Continual backprop, Dohare et al., Nature 2024 | Re-initialise low-utility units at a fixed rate inside a fixed-size net. | No growth, no novelty gating, blind constant-rate recycling; destroys rather than archives. Built as the E3 baseline (`janus/cbp.py`). |
| SET (Mocanu 2018), RigL (Evci 2020) | Prune/regrow connections under a fixed parameter budget during training. | Budget is parameter count, not bytes-per-frame; no serving signal; no archive. |
| DEN (Yoon 2018), PackNet (Mallya 2018), Progressive Nets (Rusu 2016) | Grow by changing tensor shapes at task boundaries; PackNet frees weights by pruning and reuses them. | Task boundaries required; shape changes recompile the serving graph; no live surprise trigger. |
| NORACL, 2026-04 (arXiv 2604.27031) | "Oracle-free" neuron growth per layer when effective dimension *and* Fisher-information percentile exceed thresholds; grows only, actual shape changes; offline task epochs on MNIST/CIFAR splits. | No decay, no serving, no stream, shape changes. Its two-signal "saturation" trigger is close to the E3 recommendation "surprise AND learner plateau"; Janus's trigger is the *served* signal plus plateau, and it decays. Cite it. |
| Dynamic MoE against severe distribution shifts, 2025-11 (arXiv 2511.18987) | Adds experts to MoE layers on a fixed schedule (every N steps/chunk) in CL and RL (Craftax). | Schedule-driven, not novelty-driven; no pruning; not concurrent serving. Supports the expert-block form (E3 option A) as a known mechanism; the trigger and decay are the delta. |
| Shift Happens / ShiftEx, 2025-06 (arXiv 2506.18789) | Federated MoE: creates a new expert when a client's latent statistics match no existing expert, with a flat cost per new expert. | Novelty-gated expert creation exists in federated setting. Server-side, not on-device, not serving-while-learning, no decay/archive, no bandwidth budget. |
| ETuner (was EdgeOL), 2024 (arXiv 2401.16694) | Edge device fine-tunes while handling inference requests; fine-tuning rounds triggered by data arrival and OOD-detected scenario changes; freezes converged layers. | Closest on "serve while learning on-device with an OOD trigger". No capacity growth or decay; architecture fixed; no hot-swap design. |
| Targeted incremental growth, D5AI LLC, US 11,836,600 / US 12,205,010 (priority 2020-08-20) | Grows new nodes trained standalone then merged with zero-init connections, triggered by classification errors or small gradient magnitude; node-to-node relationship regularisation. | Patent, supervised, offline, actual node insertion, no decay/archive, no serving loop, no slab. Must be cited; claims do not cover a served self-supervised surprise trigger or masked-slab serving. |
| Task-free continual learning, Aljundi et al., CVPR 2019 | Loss-plateau detection on a stream decides when to consolidate (MAS importance), no task boundaries. | Plateau-triggered *consolidation*, not growth; fixed architecture. Relevant to the "learner plateau" half of the trigger. |

## Assessment

- "Growth triggered by novelty" and "prune on disuse" are each old (GWR 2002, Garg 2017). A claim
  on either alone will not survive.
- Nothing found combines: a served self-supervised surprise signal as the trigger, concurrent
  serve-and-learn with hot-swap, decay-with-archive scored on reservoir replay, and a
  preallocated masked slab that keeps the serving engine compiled. Claims should be drafted on
  that combination, with dependent claims on (a) the masked slab / pointer-flip serving,
  (b) archive-and-page-in of decayed experts, (c) the bytes-per-frame budget as the routing
  constraint, (d) surprise gating the learner's step rate.
- E3's measured result (parity on a new regime with retention on the old ones, vs fixed and vs
  CBP) is what turns the combination from an idea into an exhibit.
